# Turn on two-step sign-in

Any authenticator app that reads TOTP codes works: the ones built into password managers too.

## Code from the app {#two-step-code}

The six digits the app shows after you scan the QR code, or type the key. They prove the app has it
right; two-step is on once they are accepted. If they are refused, check the phone's clock is set
automatically.
