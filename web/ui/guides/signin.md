# Sign in

## Username or email

Either one.

## Password

Ten wrong passwords in 15 minutes lock the username for a while.

## Code

When two-step sign-in is on, the six-digit code your authenticator app shows for MoneyKata. A new one comes every 30 seconds, and each works once. Wrong codes count like wrong passwords.

## Recovery code

One of the ten codes you saved when you turned two-step on, if your phone is lost. Each works once. With none left, ask an admin to reset your two-step sign-in.

## Forgot password?

Sends a link to choose a new one. The answer is the same whether or not the account exists.

## Account disabled

An admin made the account inactive. You can ask, once a week, to be made active again.
