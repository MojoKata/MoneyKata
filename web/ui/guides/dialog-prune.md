# Prune files

The expired files, by category: untick any to keep for now. A verified backup is made first; the
pruned files stay in the backups made before it until backup pruning removes them, so a restore can
bring them back until then. Each record keeps its row, amounts, dates and links, and shows _File
pruned_.

## Type the number of files to confirm {#prune-count}

The count, as the title says, so nothing is pruned by a slip.
