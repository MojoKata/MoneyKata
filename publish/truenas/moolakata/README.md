# MoolaKata

[MoolaKata](https://github.com/MojoKata/MoolaKata) is a self-hosted personal finance server for
a household: bank, card, brokerage, retirement, 529 and bitcoin accounts in one place, with
portfolios, projections, budgets, gifts, receipts and tax books. Its data is encrypted, and the
key is a recovery phrase that is never stored: a new server shows the phrase once to its first
admin, and starts locked after every restart until someone enters it.
