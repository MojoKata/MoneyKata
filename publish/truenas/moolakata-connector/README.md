# MoolaKata Connector

The [MoolaKata Connector](https://github.com/MojoKata/MoolaKata) keeps a MoolaKata server's
accounts current from the household's institutions. It holds their credentials itself, sealed
under 12 words that are never stored, and sends the server only what it reads. Its small page
pairs it with a MoolaKata server and unlocks it after every restart.
